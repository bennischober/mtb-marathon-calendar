# Curated Overlays

Human-written corrections to the generated calendar. Files in this directory
are applied on top of `data/generated/events.json` by `mtb-pipeline export`, so
a collection run can never overwrite a human decision.

See `docs/CURATED_DATA.md` for the file format, the fields an overlay may
change, and the review statuses.

This file is documentation, not an overlay. Only `*.json` files here are read.
